# 파주 AI-ROAD 학생 체험 웹교안

파주 AI-ROAD 찾아가는 학생 체험 프로그램의 학생용 체험 웹교안입니다.

## 파일
- `index.html` — 학생용 웹교안 전체 (이미지·기능 모두 포함된 한 개 파일)
- `dashboard.html` — 교사용 대시보드 (날짜→학교→반별 포스트잇·제출앱 모아보기, 비번 2026)

## 교사 대시보드
- 학생 주소가 `.../index.html` 이면, 대시보드는 `.../dashboard.html` 입니다.
- 대시보드는 비밀번호 **2026**으로 가려져 있어요. (학생에겐 이 주소를 알려주지 않으면 됩니다.)
- 학생용 index.html 교사 패널의 **"📊 교사 대시보드 열기"** 버튼으로도 열 수 있어요.
- ⚠️ Supabase에 아래 표(SQL)를 먼저 만들어야 대시보드가 작동합니다. (apps, class_state 테이블 + comments 태그 컬럼)

## GitHub Pages로 올리기 (학생 접속용 주소 만들기)
1. GitHub에서 새 저장소(repository)를 만듭니다. (예: `paju-ai-road`)
2. 이 폴더의 `index.html`을 저장소에 업로드합니다.
3. 저장소 **Settings → Pages** 로 이동합니다.
4. **Source**를 `Deploy from a branch`, **Branch**를 `main` / `/(root)` 으로 설정하고 Save.
5. 잠시 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다.
6. 이 주소를 단축주소·QR코드로 만들어 학생에게 공유하면 됩니다.

## 교사용 기능
- 화면 **오른쪽 위 "⚙️ 교사용"** → 비밀번호 **2026** 입력 → 교사 설정 패널 열림
  - 패들렛 주소 적용 / CSV로 저장 / 저장 후 리셋 / 리셋
- 사이드바 **"📱 접속 QR 코드"** → QR을 화면 가득 크게 표시
  - QR 이미지는 `index.html` 상단의 `QR_SITE` 값에 넣어야 표시됩니다.

## 데이터(포스트잇) 저장
- 포스트잇 댓글은 Supabase에 공유 저장됩니다. (`index.html` 상단 `SB_URL`, `SB_ANON_KEY` 참고)
- Supabase 설정이 없으면 각 기기에만 저장되는 방식으로 자동 전환됩니다.
